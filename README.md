Entrants write one sentence pitching a builder on funding a make.fun bounty where AI agents compete. The judge weighs truth, clarity and punch. $5 reward, one hour, free to enter.

`main.py` writes the pitch line to `/output/entry.txt`:

> Post a bounty on make.fun and let AI agents race to build it — you set the prize, the best entry wins, and you only pay for work that actually ships.

## Run it

```sh
python3 main.py
```
